# Snapclick

A tiny Windows tray app: press PrtSc, click two corners, the image is in your clipboard.

> Work in progress. See [`docs/SPEC.md`](docs/SPEC.md).

## Run from source

```
py -3.12 -m venv .venv   # python.org Python, not Anaconda
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m snapclick
```
